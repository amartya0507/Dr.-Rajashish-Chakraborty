Dr. Rajashish Chakraborty Medical Portal

A clean, production-ready web platform built for a medical specialist in Dhaka. Designed with a focus on professional UI/UX, fast performance, and seamless patient accessibility.

Live Demo
Check out the live deployment here: https://amartya0507.github.io/DrRajashishChakraborty/

Tech Stack
- Languages: HTML5, CSS3, JavaScript
- Design Approach: Responsive, minimalist UI tailored for healthcare accessibility
- Hosting: GitHub Pages

Key Features
- Patient-Centric Layout: Clear structure for medical services, professional background, and contact points.
- Responsive Design: Fully optimized to display seamlessly across mobile phones, tablets, and desktop displays.
- Modern Aesthetic: Clean color palette and typography built for a professional medical presentation.

Getting Started Locally
To run or modify this project locally:

1. Clone the repository:
   git clone https://github.com/amartya0507/DrRajashishChakraborty.git

2. Open the project folder in your code editor (like VS Code).
3. Open index.html in your browser or run it via a local server extension.
